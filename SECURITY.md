# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature for this repository, or contact the maintainers privately through the security contact listed in the repository settings.

Include the affected version, a description of the issue, reproducible steps, and potential impact. Please allow maintainers a reasonable opportunity to investigate and coordinate a fix before public disclosure.

## Supported versions

Security fixes are provided for the latest released version. This package has no runtime dependencies and does not execute decoded error strings.
